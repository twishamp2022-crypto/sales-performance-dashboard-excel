# 📊 Sales Performance Dashboard

An interactive Excel-based Sales Performance Dashboard designed to analyze
sales, profit, customer segments, channels, categories, regions, and monthly
sales trends.

## 📌 Project Overview

This project demonstrates how raw sales data can be transformed into an
interactive business dashboard using Microsoft Excel.

The analysis follows a simple data analytics workflow:

Raw Data → Data Cleaning → Pivot Analysis → Dashboard

The dashboard allows users to explore sales performance across different
customer segments, years, channels, regions, and product categories.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Track total orders
- Analyze profit/loss
- Identify top-performing product categories
- Compare sales across regions
- Analyze monthly sales trends
- Compare sales performance across years
- Understand customer segment performance
- Analyze different sales channels
